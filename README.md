# Arbor API

Backend API service for Arbor.

## Getting Started

1. Copy the environment template:

   ```bash
   cp .env.local.template .env.local
   ```

2. Install dependencies:

   ```bash
   bun install
   ```

3. Start the development server:

   ```bash
   bun dev
   ```
